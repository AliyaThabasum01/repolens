# 🔍 RepoLens

> AI-powered GitHub Repository Analyzer

RepoLens is a tool that analyzes public GitHub repositories and generates a structured understanding of the project, including its repository information, technology stack, file structure, strengths, weaknesses, and improvement suggestions.

## 🚀 Vision

RepoLens is being developed as an AI-powered evaluation agent that can understand software projects and provide structured feedback automatically.
